# odom

![test](https://github.com/shimazakiseita-hash/odom/actions/workflows/test.yml/badge.svg)

並進速度と角速度の列から、ロボットの自己位置を推定するコマンド

## 概要

odom（オドメトリ）は、ロボットの並進速度v、角速度ω、時間dtを1行ずつ受け取り、それを順に積み重ねてロボットの位置(x, y)と向きθを計算するコマンド。1行読むたびにその時点の位置を出力するので、ほかのコマンドとパイプでつないで使用できる。ロボットの制御の確認や、ロボコンで記録した速度のログから走行経路を確かめるなどといったデバッグに使える。積分方式は円弧（arc）とオイラー法（euler）から選べる。

## インストール

次のコマンドでリポジトリをクローンし、ディレクトリに移動する。

```
$ git clone https://github.com/shimazakiseita-hash/odom.git
$ cd odom
```

## 使い方

### 入力

- 1行に `v ω dt` を空白区切りで書く
  - v: 並進速度 [m/s]
  - ω: 角速度 [rad/s]
  - dt: 時間 [s]（0以上）
- 空行と `#` で始まる行は読み飛ばす
- `-w` を付けたときは、1列目と2列目を左右の車輪速度 vl, vr [m/s] として読む

### 出力

- 1行に `x y θ` を空白区切りで出す
  - x, y: 位置 [m]
  - θ: 向き [rad]（-π より大きく π 以下）
- 小数点以下3桁
- `-p` を付けたときは、先頭に入力の3列を付けた6列になる

### 実行例

1 m/sで前に進みながら、1秒間に90°（π/2 rad）の速さで左に曲がった場合の例。ロボットは半径約0.637 mの円の1/4を描いて進み、最後は90°左を向く。

```
$ echo '1 1.5707963267948966 1' | ./odom
0.637 0.637 1.571
```

### パイプでの使用例

例で使うファイルは`sample`ディレクトリに入っている。

速度の列を書いたファイルを標準入力から読ませる例。`tail -n 1`で最終的な位置だけを取り出し、`-d`で向きを度で確認している。

```
$ cat sample/path.txt
# v w dt
1 0 1
1 1.5707963267948966 1
1 0 1
$ ./odom < sample/path.txt
1.000 0.000 0.000
1.637 0.637 1.571
1.637 1.637 1.571
$ ./odom -d < sample/path.txt | tail -n 1
1.637 1.637 90.000
```

ロボットが記録したCSVのログから、awkで速度と時間の列だけを取り出してodomに渡す例。`NR > 1`で見出しの行を飛ばし、2〜4列目をv、ω、dtとして渡している。

```
$ cat sample/log.csv
t,v,w,dt
0.0,1,0,1
1.0,1,1.5707963267948966,1
$ awk -F, 'NR > 1 {print $2, $3, $4}' sample/log.csv | ./odom
1.000 0.000 0.000
1.637 0.637 1.571
```

### 差動二輪の場合

`-w`に左右の車輪の間隔 [m] を渡すと、左右の車輪速度から位置を計算できる。エンコーダで測った車輪速度のログをそのまま渡せる。1つ目は左車輪を止めて右車輪だけを回し、半径0.5 mの1/4円を描く例、2つ目は左右が同じ速度で直進する例、3つ目は左右を逆向きに回してその場で180°旋回する例。

```
$ echo '0 1.5707963267948966 1' | ./odom -w 1
0.500 0.500 1.571
$ echo '1 1 1' | ./odom -w 0.3
1.000 0.000 0.000
$ echo '-1.5707963267948966 1.5707963267948966 1' | ./odom -w 1
0.000 0.000 3.142
```

### 入力と結果を並べる

`-p`を付けると、入力の3列と推定位置が1行に並ぶ。どの入力のときにどこにいたかを1つのファイルに保存したり、`awk`で必要な列だけを取り出したりするのに使える。

```
$ ./odom -p < sample/path.txt
1 0 1 1.000 0.000 0.000
1 1.5707963267948966 1 1.637 0.637 1.571
1 0 1 1.637 1.637 1.571
```

### 終了ステータス

エラーが起きた場合は、何行目がなぜ不正なのかを標準エラー出力に表示して終了する。それまでに出力した結果は標準出力に残る。

| 終了ステータス | 意味 |
| --- | --- |
| 0 | 正常終了（空入力を含む） |
| 1 | 入力の誤り（列の数が3でない、数値でない、nan・inf、dt が負） |
| 2 | オプションの誤り |
| 130 | Ctrl+Cで中断 |

## オプション

| オプション | 説明 |
| --- | --- |
| `-m {arc,euler}` | 積分方式。デフォルトは `arc` |
| `-i X,Y,TH` | 初期位置。カンマ区切りで、TH の単位は rad |
| `-d` | θ を度で出力する |
| `-w W` | 車輪間距離 [m]。入力を `vl vr dt` として読む |
| `-p` | 各行の先頭に入力の3列を付けて出力する |

`-w`のWには正の数を指定する。0以下や数値でない値を指定するとエラーになり、終了ステータス2で終了する。

`-p`と`-w`を一緒に使うと、先頭に付くのは変換する前の`vl vr dt`になる。

`-i`で負の値から始める場合は、`-i=-1,2,0`のように`=`でつないで指定する。`-i -1,2,0`と書くと、`-1,2,0`がオプションとして解釈されてエラーになる。

arcは、ロボットが一定の速度で曲がりながら円弧を描いて進むとして計算する。eulerは、dtの間は向きを変えずにまっすぐ進み、そのあとで向きを変えるとして計算する。同じ入力でも、dtが大きいほどeulerの誤差は大きくなる。例えば上の実行例を`-m euler`で計算すると、結果は`1.000 0.000 1.571`になる。
